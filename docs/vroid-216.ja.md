# VRoid Studio 2.16.0 に関するメモ

このフォークは、Windows 上の **VRoid Studio 2.16.0** を対象にしています。
ドライバーのコード自体はフォーク元の Windows 版から変更していません。
この文書では、そのまま使える見込みである理由、2.16.0 での変更点、
実作業の前に確認すべきことをまとめます。

## VRoid Studio 2.14.0 → 2.16.0 の変更点

pixiv 公式のアップデート告知より：

* **v2.16.0**（2026-10-28）
  * 新機能：髪型編集でヘアー形状を保存可能に
  * 新機能：設定に「パフォーマンス表示」を追加。オンにするとモデル編集中、
    画面左下に FPS・VRAM 消費量・RAM 消費量が表示される
  * 修正：透明度保護がかかった状態で消しゴムを使うと黒く描画される不具合
* Steam のニュースフィードに 2.15.x の告知はなく、この範囲の告知済み変更に、
  エディターのタブ列・パラメーターパネル・VRM 書き出しフローの変更は含まれていません。

## コード変更が不要だった理由

* Windows 版バックエンドは、VRoid の判定をバージョン付きウィンドウタイトルではなく
  プロセス（`VRoidStudio.exe`）で行うため、バージョンが上がっても
  ウィンドウ検出やフォーカスガードは壊れません。
* 位置特定のアンカーは、OCR で読む UI テキスト（`Export`、`Parameters`、タブ名など）と、
  2.14.0 で測定した相対位置です。2.14.0 → 2.16.0 の変更には、
  これらの名前変更や移動は含まれていません。
* Steam 版以外の起動はもともと対応済みです。`MCP_VROID_EXE` にインストール済みの
  `VRoidStudio.exe` のフルパスを指定すれば、公式サイト版も BOOTH 版も起動できます。

## 配布形態ごとの起動方法

| 配布形態 | 起動方法 |
|---|---|
| Steam 版（アプリID `1486350`） | 従来どおり Steam 経由 |
| 公式サイト版（単体インストーラー） | `MCP_VROID_EXE` にインストール先の `VRoidStudio.exe` のフルパス |
| BOOTH 版 | 従来どおり `MCP_VROID_EXE` |

## 実作業の前の確認手順

アンカーの校正自体は 2.14.0 のままなので、対象マシンで以下の確認を一度通すまでは、
2.16.0 対応は「動く見込み・未検証」として扱ってください。

1. VRoid Studio の UI 言語を **英語** にする
   （ケバブメニュー `⋮` → Settings → Language → English）。
   日本語 UI では OCR の目印が一致しません。
2. **パフォーマンス表示はオフ** のままにする（設定）。オンだと編集画面の左下に
   FPS 等が重なって写り、撮影や OCR の邪魔になります。
3. 表示倍率は **100%** を推奨します。相対位置のアンカーは 2560×1440 で調整したもの
   （書き出しフローは除く）で、他の解像度では再測定が要る場合があります。
4. `uv run python scripts/smoke_test.py` を実行し、次に `vroid_status` を呼ぶ。
5. **使い捨てモデル** で、受け入れ確認のフェーズを順に実行する：
   `create`、`edit`、`color`、`save`、`export10`
   （`uv run python scripts/windows_acceptance.py <フェーズ>`）。
   書き出されたファイルが正しい VRM 1.0 であることを確認します。
6. 結果を README の「動作確認済み環境」の表に記録する。
7. フェーズが失敗したら、無理に進めないこと。見つからなかったテキストやアンカーを記録し、
   `docs/ui-map.md` の形式で再測定して、測定した環境とあわせて記録してください。

## 2.16.0 固有の注意

* 髪型編集には 2.16.0 でヘアー形状の保存 UI が増えています。髪型編集は
  もともとこのサーバーでは未検証の領域なので、バージョンによらず
  髪型編集の自動操作はすべて未検証として扱ってください。
* pixiv サインイン／Premium の UI（2.14.0 で追加）は、どのフローでも使わないため、
  アカウントは不要です。
